Screenshot / evidence guide for report

1. What is this finding?

This is a dependency vulnerability issue. The problem is not a bug inside your route/controller .js logic. Vulnerable versions are declared and locked in the npm package files, then installed into node_modules.

For the report: show package.json + package-lock.json + terminal npm audit output. Do not look for a CVE line inside AdminRoute or email files (that was Finding #2).

Affected file(s): backend/package.json, frontend/package.json
(and their lockfiles: backend/package-lock.json, frontend/package-lock.json)

Method: Software Composition Analysis (npm audit)

Example findings:
- multer <=1.4.4-lts.2 — CVE-2022-24434 (DoS via malformed multipart body)
- body-parser <=1.20.6 — GHSA-qwcr-r2fm-qrc7 (DoS)

Remediation direction:

pin versions, recurring dependency scanning.
